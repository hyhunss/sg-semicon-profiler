# Changelog

All notable changes to this plugin are documented in this file.

## 0.6.0 - 2026-08-19

- Streamlined Skill 1 into Core Competencies, Sourced Evidence, and Targeting Vectors.
- Removed the Important limitations section from Skill 1 instructions and its OKF sample.
- Updated Skills 2 and 3 to consume the new three-pillar capability profile.

## 0.5.0 - 2026-08-19

- Breaking: Skill 3 and Skill 4 now accept only qualified-prospects schema version 1.4.0.
- Removed consolidated legacy prospect-input fallback and legacy dashboard rendering.
- Made all v1.4.0 decision, evidence-access, source-directory, and score-breakdown fields mandatory in the schema.

## 0.4.0 - 2026-08-19

- Added the root Agent Plugins v1.0.0 manifest.
- Verified all four workflows follow the Agent Skills directory and frontmatter requirements.
- Preserved the Codex-native manifest for existing Codex installations.
